## 🎯 Overview

This portfolio is a **full-stack web application** designed to showcase my skills, projects, certifications, and professional journey. It combines a sleek **React + TypeScript** frontend with a robust **Node.js + Express** backend, backed by **MongoDB Atlas** for persistent data storage. The entire application is deployed on **Vercel** (frontend) and **Render** (backend) for seamless, production-grade performance.

## 🚀 Features

| Feature | Description |
|:--------|:------------|
| 🎬 **Animated Hero Section** | Eye-catching typewriter effect paired with an interactive particle background that draws visitors in instantly. |
| 🧠 **Interactive Skills Section** | Animated progress bars with categorized tech stacks — visually representing proficiency across languages, frameworks, tools, and databases. |
| 🃏 **Projects Showcase** | Glassmorphism-styled project cards with **status badges** (Deployed / Academic), **category filters** (All, Blockchain, Full Stack, AI & Full Stack), highlight chips, and direct links to GitHub repos, live demos, and deployments. |
| 📅 **Education & Experience Timeline** | Interactive timeline with progressive scroll animations and an elegant alternating left-right layout that narrates the professional journey. |
| 🏆 **Certifications & Achievements** | Grid layout with SVG avatars and built-in modal viewers for PDFs and images — showcasing Java certifications, Red Hat credentials, GATE 2026, LeetCode 50/100 day streaks, and Daily Coding Challenge badges (March, April & May 2026). |
| 📬 **Contact Form** | Fully functional contact form with **MongoDB persistence** and real-time **email notifications via Resend** — never miss an inquiry. |
| 📥 **CV Download** | Download resume in both **PDF** and **DOCX** formats, served directly from the backend API. |
| 🌗 **Dark / Light Theme** | Smooth theme toggle with fluid CSS transitions for a comfortable viewing experience in any environment. |
| 📱 **Fully Responsive** | Pixel-perfect design across **desktop**, **tablet**, and **mobile** — ensuring a premium experience on every screen size. |
| 🔍 **SEO Optimized** | Proper meta tags, semantic HTML, Open Graph tags, and structured heading hierarchy for maximum search engine visibility. |

## ⚙️ Local Setup

> **Prerequisites:** Node.js ≥ 18, npm, Git, MongoDB Atlas account (or local MongoDB)

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Tusharparihar05/Portfolio.git && cd portfolio
```

### 2️⃣ Setup Backend

```bash
cd server
npm install
cp .env.example .env
```

Fill in the environment variables in `.env` (see [Environment Variables](#-environment-variables)), then start the server:

```bash
node server.js
```

### 3️⃣ Setup Frontend

```bash
cd client
npm install
cp .env.example .env
```

Set the API URL in `.env`:

```env
VITE_API_URL=http://localhost:5000
```

Start the development server:

```bash
npm run dev
```

### 4️⃣ Open in Browser

```
Frontend  →  http://localhost:5173
Backend   →  http://localhost:5000
```

## 🔐 Environment Variables

### Backend (`server/.env`)

| Variable | Description | Example |
|:---------|:------------|:--------|
| `PORT` | Server port number | `5000` |
| `MONGODB_URI` | MongoDB Atlas connection string | `mongodb+srv://user:pass@cluster.mongodb.net/portfolio` |
| `JWT_SECRET` | Secret key for JWT tokens | `your_jwt_secret_here` |
| `RESEND_API_KEY` | API key for Resend email service | `re_xxxxxxxxxx` |

### Frontend (`client/.env`)

| Variable | Description | Example |
|:---------|:------------|:--------|
| `VITE_API_URL` | Backend API base URL | `http://localhost:5000` |
